Workbuddy Token消耗看板

选择本机的 WorkBuddy 日志目录，即可在浏览器内直接扫描并查看你的 Token 消耗。

所有解析与计算都只在你的浏览器本地完成，日志不会上传到任何服务器。

日志目录 ~/.workbuddy/projects
macOS
显示隐藏目录：⌘ ⇧ .（访达或选择框内切换）
直达该目录：⌘ ⇧ G 后粘贴路径
Windows
显示隐藏目录：Alt → V → H（查看 → 隐藏的项目）
直达该目录：地址栏直接粘贴路径
推荐 Chrome / Edge；若浏览器不支持目录选择，将自动改用「选择文件夹」文件框。下次会自动打开到你上次选的目录。
